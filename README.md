# TV Streaming — Indonesia & Luar Negeri

Web direktori channel TV: grid khusus **TV Indonesia** + grid **TV Luar
Negeri** (fokus Asia: Korea, Jepang, Singapura, Malaysia, Thailand, dst.)
dengan Flag Grid — klik bendera negara buat nyaring channel negara itu.

Tiap kartu: logo + nama channel + kategori. Klik channel buat nonton di
player (stream publik) atau buka situs resminya.
