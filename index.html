🚀 Mau di-upload ke GitHub Pages?

Halaman ini memang disiapkan sebagai 1 file index.html — jadi gampang banget dipindah ke GitHub Pages. Nanti tinggal upload file ini saja, situsnya langsung online gratis.

1

Buat Repo Baru

Di GitHub → New repository, misal namanya tv-streaming → Public → Create.

2

Upload index.html

Add file → Upload files → pilih file index.html ini → Commit changes.

3

Aktifkan Pages

Settings → Pages → Source: Deploy from a branch → Branch main / (root) → Save. Tunggu 1–2 menit, link username.github.io/tv-streaming jadi.

Catatan: Player memakai embed live resmi YouTube & stream HLS publik dari masing-masing stasiun / distributor resminya. Hak siar tetap milik stasiun TV-nya — kalau ada channel yang keberatan, cukup hapus channel itu dari daftar.

Dibuat untuk Dedi Rohadi • Indonesia dipisah sendiri: nasional + lokal/daerah (Jabar, Jakarta, Jateng, DIY, Jatim, Bali, Sumatera, Kalimantan, Sulawesi, Papua), luar negeri fokus Asia (Korea & Jepang duluan) dengan Flag Grid per negara • Player: embed YouTube Live + HLS.js — mendukung Chrome, Edge, Firefox & Safari.
